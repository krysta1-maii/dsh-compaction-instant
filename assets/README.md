# Plugin icon

[icon.svg](<icon.svg>) adapts the [Lucide Shrink icon](https://lucide.dev/icons/shrink) from [Lucide 0.468.0](https://github.com/lucide-icons/lucide/blob/0.468.0/icons/shrink.svg). The four inward-pointing arrows represent context compaction.

The original path geometry is unchanged. The adaptation adds an indigo rounded-square background, uses white strokes, and scales the artwork into a 64 × 64 view box so it remains legible on both light and dark plugin cards. It is bundled locally; rendering does not contact an external image host.
